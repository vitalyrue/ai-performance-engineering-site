Appendix A — Libraries and frameworks used in the book

Libraries provide operations such as searching an index or validating returned fields. The surrounding software still needs rules for access, data updates, acceptable results, and failure handling. The table separates those tasks and identifies records that help check their behavior. The reference architecture in Section 12.1 shows where each library sits in one system.
