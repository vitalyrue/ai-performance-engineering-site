Appendix G — External research and dated supplements

Primary research establishes method origins, while official documentation defines versioned implementation behavior. Provider, library, and protocol behavior can change, so dated supplements are not timeless claims. Every external claim retains its source, version or publication date, access date, and the section where it is explained.

The dated references support implementation choices that can change over time. Recheck provider prices, model identifiers, library interfaces, protocol drafts, and authorization requirements before implementation.
