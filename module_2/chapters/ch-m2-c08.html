8  Cross-entropy and perplexity

Decoding selected an output from a fixed model’s distribution. Training asks a different question: how much probability did that model assign to the observed target? A model that gives the correct answer probability 0.01 should incur a greater penalty than one that gives it probability 0.8.

Negative log likelihood turns that comparison into a loss. Combining the losses gives a training objective, while perplexity expresses average token loss on a different scale. The same mathematics also separates uncertainty in the data from disagreement with a model.

8.1 Loss from a target probability

A correct-or-incorrect decision gives zero-one loss: zero for a correct predicted class and one for an error. With a positive target and threshold 0.5, probabilities 0.1 and 0.4 both incur loss one. That score hides the improvement in target probability.

As a function of the underlying score, zero-one loss is flat away from its decision boundary and discontinuous at the boundary. It provides no useful local direction for the gradient updates developed later. A probability-sensitive loss preserves information that the hard decision discards.

Suppose the observed target has probability 0.25 under a model. The negative log likelihood, or NLL, assigns the penalty \(-\log(0.25)\approx1.386\). A probability of 1 gives zero penalty, and probabilities approaching zero give increasingly large penalties.

\[ \mathrm{NLL}=-\log P_\theta(y\mid x) \tag{8.1}\]

The input is \(x\), the observed target is \(y\), and \(\theta\) denotes the model parameters. The expression \(P_\theta(y\mid x)\) is the probability assigned to that target. A likelihood regards the observed data as fixed and asks how well the model parameters explain it. Taking a negative logarithm converts maximizing that probability into minimizing a penalty.

Natural logarithms measure this loss in nats. A nat is an information unit using base \(e\). Dividing a value in nats by \(\log 2\) converts it to bits. Thus one nat is approximately 1.443 bits. The negative logarithm is also called surprisal: an event assigned a small probability carries a large value.

For a binary outcome, sigmoid supplies probability \(p\) for target 1 and \(1-p\) for target 0. The observed-label likelihood is \(p^y(1-p)^{1-y}\). Taking its negative logarithm gives binary cross-entropy, or BCE:

\[ L_{\mathrm{BCE}}=-y\log p-(1-y)\log(1-p) \tag{8.2}\]

Here \(y\in\{0,1\}\). When \(y=1\), the second term vanishes and the loss is \(-\log p\). When \(y=0\), the first term vanishes and the loss is \(-\log(1-p)\). For a positive target, \(p=0.8\) gives about 0.223 nats, while \(p=0.1\) gives about 2.303 nats. The latter prediction assigns much less probability to what actually occurred.

For a categorical outcome, a one-hot target is a vector with 1 at the observed class and 0 elsewhere. If there are three classes and the observed class index is 1, its one-hot vector is \([0,1,0]\). Categorical cross-entropy compares that target with the predicted probability vector:

\[ L_{\mathrm{CE}}=-\sum_i y_i\log p_i \tag{8.3}\]

The index \(i\) runs over classes, \(y_i\) is the target indicator, and \(p_i\) is the corresponding model probability. Only the observed class contributes to the sum. If its class index is \(c\), this simplifies to:

\[ H(\mathbf y,p)=-\sum_i y_i\log p_i=-\log p_c,\quad y_c=1 \tag{8.4}\]

For model probabilities \([0.2,0.7,0.1]\) and target index 1, the loss is \(-\log(0.7)\approx0.357\). A target receiving probability 0.25 gives 1.386 nats, matching the NLL example. The vector formula and the observed-class formula therefore describe the same calculation for a one-hot target.

The figure connects a target’s probability to its penalty. High confidence is useful only when it favors the observed outcome.

A large loss identifies a poorly predicted target. It does not alone determine how much every parameter will change. That also depends on the derivatives through the model and the update rule, introduced in backpropagation.

Implementations should preserve the numerical stability established in Section 6.3. BCEWithLogitsLoss receives raw binary logits and targets of matching shape. CrossEntropyLoss can receive categorical logits and integer class indices, avoiding an explicit one-hot array. It combines the stable log-probability calculation with target selection. Passing sigmoid or softmax probabilities into an interface expecting logits would apply the wrong transformation.

8.2 Combining valid losses

We can now calculate the three penalties that Chapter 1 supplied without derivation. The running batch has targets \([1,0,1]\) and sigmoid probabilities approximately \([0.711,0.450,0.646]\). Their losses are \(-\log(0.711)\approx0.341\), \(-\log(1-0.450)\approx0.598\), and \(-\log(0.646)\approx0.437\).

The mean is \((0.341+0.598+0.437)/3\approx0.459\). This is the empirical-risk average, now applied to a specified loss. The separate example with supplied penalties 0.2 and 0.5 gives \((0.2+0.5)/2=0.35\) by the same rule.

A reduction combines several loss values through a sum, mean, or another stated rule. A sum gives a larger objective when more equally difficult examples contribute. A mean divides by their count. That scaling later affects the gradient as well, so a change of reduction is part of the training configuration.

The runnable PyTorch example below starts from the running batch’s fixed logits. It returns each binary loss before taking the mean, then compares that mean with the library’s default reduction. It separately checks a categorical target using log probabilities supplied as valid logits.

Code example: Separate binary losses and a categorical target

import math
import torch
import torch.nn.functional as F

logits = torch.tensor([0.9, -0.2, 0.6])
targets = torch.tensor([1.0, 0.0, 1.0])
per_example = F.binary_cross_entropy_with_logits(logits, targets, reduction="none")
mean_loss = per_example.mean()
assert torch.allclose(mean_loss, F.binary_cross_entropy_with_logits(logits, targets))

# These supplied positive probabilities have logarithms that are valid logits.
class_probabilities = torch.tensor([[0.2, 0.7, 0.1]])
class_target = torch.tensor([1])
categorical_loss = F.cross_entropy(class_probabilities.log(), class_target)
assert math.isclose(categorical_loss.item(), -math.log(0.7), rel_tol=1e-6)
print(per_example.tolist(), mean_loss.item(), categorical_loss.item())

The binary mean is approximately 0.45893. The categorical loss is approximately 0.35667. These checks measure probability-to-loss arithmetic and make no parameter update.

Language modeling applies the same observed-target rule at sequence positions. For token \(x_t\) and its permitted prefix, the local loss is:

\[ L=-\log P_\theta(x_t\mid x_{<t}) \tag{8.5}\]

Chapter 1’s within-sequence alignment uses a sequence of \(T\) tokens to supply \(T-1\) next-token targets. With no excluded targets, their average is:

\[ L_{\mathrm{LM}}(\theta)=-\frac{1}{T-1}\sum_{t=1}^{T-1}\log P_\theta(x_{t+1}\mid x_{\le t}) \tag{8.6}\]

The prediction at position \(t\) uses \(x_{\leq t}\) and is judged against \(x_{t+1}\). The condition \(T\geq2\) ensures at least one such pair. Additional beginning-token conventions must be stated separately.

Real batches can include padding and deliberately unsupervised positions. A loss mask identifies which target positions contribute to the objective. If \(M>0\) positions are supervised, the mean uses exactly those positions:

\[ \mathrm{CE}=-\frac{1}{M}\sum_{t\in\mathrm{unmasked}}\log P_\theta(x_t\mid x_{<t}) \tag{8.7}\]

Here \(M\) is a count, rather than a mask tensor. The index set in the sum identifies the valid targets. Both the numerator and denominator exclude padding and other ignored targets. If no target is valid, the training procedure must skip or reject that batch rather than divide by zero.

For correct-token probabilities 0.7 and 0.5, the mean loss is \(-(\log0.7+\log0.5)/2\approx0.525\). If a third stored position is padding, it neither adds a loss nor changes the divisor to 3. Dividing by storage length would make examples look artificially easier when more padding is added.

There are two common alignment interfaces. A direct loss calculation pairs logits[:, :-1, :] with next-token labels input_ids[:, 1:]. A causal language-model class such as GPT-2 can instead receive labels aligned with input_ids and perform that shift internally. Shifting both in preparation and inside the model would skip a target position and change the task.

The next runnable example uses the two padded ID rows from Chapter 2 and fixed, zero logits over a ten-token vocabulary. The predictions have shape \([2,4,10]\). Shifting leaves three possible target positions per row, of which five are valid. Flattening only the batch and sequence axes produces the \([N,V]\) logits expected by this direct cross-entropy call.

Code example: Next-token alignment with five valid targets

import math
import torch
import torch.nn.functional as F

input_ids = torch.tensor([[1, 4, 8, 9], [1, 6, 9, 9]])
valid = torch.tensor([[True, True, True, True], [True, True, True, False]])
vocabulary_size = 10
logits = torch.zeros(2, 4, vocabulary_size)

targets = input_ids[:, 1:].clone()
targets[~valid[:, 1:]] = -100
predictions = logits[:, :-1, :].reshape(-1, vocabulary_size)
flat_targets = targets.reshape(-1)
per_target = F.cross_entropy(predictions, flat_targets, ignore_index=-100, reduction="none")
active = flat_targets != -100
count = int(active.sum())
assert count == 5
assert targets[1, 1].item() == 9
assert targets[1, 2].item() == -100
mean_loss = per_target[active].sum() / count
library_mean = F.cross_entropy(predictions, flat_targets, ignore_index=-100)
assert torch.allclose(mean_loss, library_mean)
assert math.isclose(mean_loss.item(), math.log(vocabulary_size), rel_tol=1e-6)
print(count, mean_loss.item(), mean_loss.exp().item())

The real EOS in the shorter row remains a target, while its inserted padding is ignored. Every zero-logit row is uniform over ten tokens, so each valid loss is \(\log10\approx2.303\). The total and count produce that same mean across the five valid positions.

A mean over tokens gives each supervised token equal influence. A mean of per-document means gives documents equal influence instead. Those objectives can differ when document lengths differ. State the intended unit before comparing losses across datasets or batches.

8.3 Perplexity

An average token loss is additive in logarithms. Perplexity puts it back on a multiplicative scale by exponentiating the mean:

\[ \mathrm{PPL}=\exp(\mathrm{CE}) \tag{8.8}\]

The expression assumes natural-log cross-entropy. If base-2 logarithms were used, the corresponding inverse would be \(2^{\mathrm{CE}}\). A loss of 1.2 nats gives \(e^{1.2}\approx3.32\), and a loss of 2.0 gives approximately 7.39.

Perplexity is the inverse geometric mean of the probabilities assigned to observed targets. It can be understood through a uniform distribution: if every one of \(V\) tokens receives probability \(1/V\), the token loss is \(\log V\) and perplexity is exactly \(V\). This is an effective-choice interpretation, rather than a literal count of plausible outputs at every position.

Consider The cat sat on, with toy IDs \([1,2,3,4]\) and a vocabulary of 5,000 tokens. Input positions \([1,2,3]\) have targets \([2,3,4]\), and their logits have shape \([1,3,5000]\). The model width can be 64 without changing that vocabulary-output shape.

With uniform output probabilities, each target has probability \(1/5000=0.0002\). Its loss is \(\log5000\approx8.517\) nats, and perplexity is exactly 5,000 before rounding. If each observed target instead receives probability 0.3, the mean loss is \(-\log0.3\approx1.204\) and perplexity is \(1/0.3\approx3.333\). Neither value by itself establishes how the model obtained those predictions.

The inverse relation also clarifies what \(e^{-L}\) measures when \(L\) is mean negative log probability. It is the geometric mean of the observed-target probabilities, obtained by multiplying them and taking the appropriate root. For probabilities 0.9 and 0.1, it equals \(\sqrt{0.09}=0.3\), while their arithmetic mean is 0.5. Exponentiating negative average loss does not generally recover arithmetic mean confidence.

Lower perplexity means higher geometric-mean probability for the observed targets under the stated evaluation conditions.

Compare perplexities only when the evaluated text, tokenizer, target selection, and aggregation convention are compatible. Changing the tokenizer changes the unit called a token. A model can also lower next-token perplexity without improving an application’s desired output format or factual reliability.

8.4 Entropy and distribution mismatch

Even an accurate probability model can remain uncertain about an outcome. To separate that inherent uncertainty from model disagreement, consider a target distribution \(p\) and a model distribution \(q\). In this section, \(p\) describes how outcomes occur, rather than the predicted distribution used earlier.

Entropy is the average surprisal when a distribution predicts outcomes drawn from itself:

\[ H(p)=-\sum_i p_i\log p_i \tag{8.9}\]

Each outcome’s \(-\log p_i\) is weighted by the probability \(p_i\) of observing it. For \(p=(0.5,0.5)\), entropy is \(-0.5\log0.5-0.5\log0.5\approx0.693\) nats. A certain outcome has entropy zero. A uniform distribution over \(K\) outcomes has entropy \(\log K\).

General cross-entropy uses the model probabilities to score those same target outcomes: \(H(p,q)=-\sum_i p_i\log q_i\). Earlier, the observed categorical label supplied a one-hot target distribution. This broader expression also allows a target with probability spread across outcomes.

For target \(p=(0.5,0.5)\) and model \(q=(0.75,0.25)\), cross-entropy is \(-0.5\log0.75-0.5\log0.25\approx0.837\). The target’s entropy was about 0.693, so using the mismatched model adds about 0.144 nats of average loss.

That excess is the Kullback-Leibler divergence, abbreviated KL divergence:

\[ \operatorname{KL}(p\mathbin\Vert q)=\sum_i p_i\log\left(\frac{p_i}{q_i}\right) \tag{8.10}\]

Subtracting entropy from cross-entropy gives \(\sum_i p_i(\log p_i-\log q_i)\), which is the displayed log-ratio expression. Therefore \(H(p,q)=H(p)+\operatorname{KL}(p\Vert q)\). The divergence is nonnegative for probability distributions and is zero when they agree.

KL divergence is not a symmetric distance: exchanging \(p\) and \(q\) generally changes it. Terms with \(p_i=0\) contribute zero by the limiting convention. If \(p_i>0\) while \(q_i=0\), the divergence and cross-entropy are infinite. These conditions matter when a model rules out an outcome that can actually occur.

The loss now measures both prediction fit and, when distributions are compared, the cost of mismatch. An application’s task metric can ask a different question, such as how many decisions were correct. The next chapter keeps those measurements distinct when judging behavior on held-out data.
