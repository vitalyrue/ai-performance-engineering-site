15  Recurrent networks

The order of words can change a sentence’s meaning even when its token counts remain identical. A sequence model needs a way to retain information about earlier positions. We begin with a fixed history, then replace that explicit suffix with a learned state.

The progression concerns how a prediction uses context. It also exposes a limitation: a compact recurrent state requires a sequence of dependent updates. The attention mechanism in Chapter 16 will offer a different way to connect positions.

15.1 Sequence outputs

Pooling static embeddings loses order, as Section 13.3 demonstrated. Before choosing an order-sensitive model, establish which outputs the task requires. Different output arrangements lead to different targets and inference procedures.

A sequence acceptor reads an input sequence and returns one decision, such as a review’s sentiment. Sequence labeling returns one label for each input position. A sequence transducer maps an input sequence to an output sequence, whose length need not match the input.

Translation is a transduction task. Token tagging is an aligned case with one label per position. Neither term specifies whether the implementation uses recurrence or attention.

An autoregressive model, introduced in Section 1.2, predicts each output token from an available prefix. Its outputs become inputs to subsequent predictions during generation.

For a batch of \(B\) sequences, one classification target per sequence has shape \([B]\). Tagging \(T\) positions requires targets shaped \([B,T]\). A generated sequence needs its own output length and stopping rule, as in Chapter 7.

These requirements determine which information must reach each prediction. The simplest language-model baseline stores only a short suffix of the preceding text.

15.2 Fixed histories

The full next-token distribution conditions on every earlier token. Many exact prefixes occur only once, making direct counting impractical. An n-gram model reduces the history to the most recent \(n-1\) tokens.

This Markov assumption treats that suffix as sufficient for the next prediction.

\[ P(x_{t}\mid x_{<t})\approx P\!\left(x_{t}\mid x_{t-n+1},\ldots,x_{t-1}\right) \tag{15.1}\]

A bigram model uses one preceding token. A trigram uses two. For example, a trigram approximates \(P(\text{sat}\mid\text{the cat slept})\) by \(P(\text{sat}\mid\text{cat slept})\). It has no way to distinguish earlier prefixes that end with the same two tokens.

Training starts by counting complete history-and-next-token events. For the sentences “cat sat”, “cat sat”, and “cat ate”, insert explicit start and end markers. Each sentence then contributes adjacent bigrams such as \((\text{START},\text{cat})\), \((\text{cat},\text{sat})\), and \((\text{sat},\text{END})\).

The history “cat” has three observed successors: “sat” twice and “ate” once. Maximum-likelihood estimation, or MLE, assigns each successor its observed relative frequency.

\[ P(w_t\mid\mathrm{context})=\frac{\operatorname{count}(\mathrm{context},w_t)}{\operatorname{count}(\mathrm{context})} \tag{15.2}\]

The denominator counts the successor events for that history. Thus \(P(\text{sat}\mid\text{cat})=2/3\) and \(P(\text{ate}\mid\text{cat})=1/3\). In a separate count row with three occurrences of one continuation among ten events, its probability is \(3/10=0.3\).

Boundary handling matters because the model must represent sentence starts and ends consistently. For higher orders, left padding can supply \(n-1\) start markers. A marker contributes a model event, rather than ordinary article text. Split the corpus before counting to keep evaluation examples out of the estimated probabilities.

The MLE assigns zero probability to an unseen successor under a seen history. A completely unseen history has denominator zero, so the frequency ratio alone does not define its distribution. A vocabulary policy and a fallback rule are necessary before evaluating arbitrary text.

An unknown token collects items excluded from the training vocabulary. Replacing rare training words with that token lets the model estimate events involving it. Merely defining an unknown ID does not create any observed counts for it.

Smoothing reserves probability for events absent from the counts. As a book extension, consider add-alpha smoothing, which adds a positive pseudocount \(\alpha\) to every allowed successor. For history \(h\), the estimate becomes \(P(w\mid h)=[C(h,w)+\alpha]/[C(h)+\alpha|V_{\text{out}}|]\).

Here \(V_{\text{out}}\) is a fixed output vocabulary. With observed successor counts \((2,1,0,0)\) and \(\alpha=1\), the denominator is \(3+4=7\). The probabilities become \((3/7,2/7,1/7,1/7)\) and sum to one.

The unobserved events can now be scored, but probability has been removed from the observed events. A large pseudocount can overwhelm limited data. Backoff instead uses a shorter history when a longer one lacks sufficient evidence. These are modeling choices whose effects require held-out evaluation.

The NLTK experiment in Section 24.3 develops the complete count, score, generation, and persistence workflow. The source notebook requires the MLE procedure and lists smoothing as optional reading. The smoothing calculation here explains an important limitation before we move beyond fixed histories.

Increasing \(n\) exposes more context but creates more possible histories and sparser observations. A learned state offers a different trade-off: it compresses earlier information into a fixed-width vector.

15.3 Updating recurrent state

A fixed suffix discards everything outside its window. A recurrent neural network, or RNN, instead updates a hidden state as it reads each input. The state can depend on the whole preceding sequence, subject to what its learned update retains.

An RNN cell is the repeated function that combines the current input vector \(x_t\) with the previous state \(h_{t-1}\). In this section, \(x_t\) denotes a floating-point input vector, not the integer token ID used in the n-gram equations.

\[ h_{t}=\phi(W_{x}x_{t}+W_{h}h_{t-1}+b) \tag{15.3}\]

For input width \(d\) and state width \(H\), \(W_x\) has shape \([H,d]\) and \(W_h\) has shape \([H,H]\). The bias and state have \(H\) coordinates. The same matrices are reused at every step, and \(h_0\) supplies the initial state.

The activation \(\phi\) makes this a nonlinear transition, following Chapter 12. A common choice is \(\tanh\), whose output lies between \(-1\) and \(1\).

For a scalar calculation with identity activation, let \(W_x=2\), \(W_h=0.5\), \(x_t=3\), \(h_{t-1}=4\), and \(b=0\). The next state is \(2(3)+0.5(4)=8\). With both weights equal to one, \(x_t=2\) and \(h_{t-1}=1\) instead produce preactivation 3. A \(\tanh\) activation would turn that preactivation into approximately \(0.9951\).

A two-coordinate example shows the same operation without collapsing the state to a scalar. Set \(x_t=(1,0)\), \(h_{t-1}=(0.5,-0.5)\), \(W_x=I\), \(W_h=0.2I\), and \(b=0\). The preactivation is \((1.1,-0.1)\), giving \(h_t\approx(0.800499,-0.099668)\) after \(\tanh\).

The new state can supply an output immediately. A language-model head maps it to one logit per vocabulary item.

\[ z_{t}=W_{y}h_{t}+b_{y} \tag{15.4}\]

Here \(W_y\) has shape \([|V|,H]\), \(b_y\) has \(|V|\) coordinates, and \(z_t\) has shape \([|V|]\). For \(h_t=(1,2)\), identity output weights and zero bias give logits \((1,2)\). No extra activation is needed before the stable cross-entropy loss.

For a batch, inputs have shape \([B,T,d]\) and the stored states have shape \([B,T,H]\). A vocabulary head produces logits \([B,T,|V|]\). A tagging head instead uses its label count as the final axis. An acceptor can use a final valid state for one decision.

The recurrence creates a new dependency at every position. Training must assign each error to all the shared parameter uses that contributed to it.

15.4 Gradients through time

Backpropagation already handles a chain of operations, as Chapter 10 established. Backpropagation through time, or BPTT, applies it to the recurrent cell repeated across sequence positions. Unrolling makes each parameter use visible while retaining one shared parameter tensor.

A loss at the final position depends on earlier states through every intervening transition. For the scalar recurrence \(h_t=\rho h_{t-1}+x_t\), its derivative with respect to a state ten steps earlier is \(\rho^{10}\). If \(\rho=0.5\), that factor is about \(0.000977\). If \(\rho=1.5\), it is about \(57.67\).

A vanishing gradient becomes too small to carry an effective learning signal along this path. An exploding gradient grows excessively. With nonlinear cells, local activation derivatives also enter the product. Matrix transitions can amplify some directions while shrinking others.

Gradient clipping from Section 11.7 bounds a large computed gradient. It does not restore an earlier signal that has already vanished. Truncated BPTT limits the backward path to a chosen segment, usually by detaching the carried state between segments. The state values can continue forward even though later gradients cannot cross that boundary.

For next-token training, teacher forcing supplies the observed previous token as the next decoder input. Writing that input ID as \(u_t\) gives:

\[ u_{t}=x_{t-1}^{\mathrm{gold}} \tag{15.5}\]

The superscript “gold” identifies the recorded target sequence. An embedding lookup converts \(u_t\) to the floating-point vector consumed by the recurrent cell. The shift, validity mask, and token-loss reduction follow Section 1.2 and Section 8.2.

Generation supplies the model’s selected token instead. Exposure bias describes the resulting difference between observed training prefixes and self-generated prefixes. An early incorrect token can change later inputs and states. Decoding choices remain those in Chapter 7.

Repeated state transformations make retaining information difficult. A gated cell adds a more direct path for carrying selected values forward.

15.5 Gated memory

A plain RNN transforms its entire state at every step. Long short-term memory, or LSTM, separates a carried cell state \(c_t\) from the exposed hidden state \(h_t\). Learned gates control how much information each coordinate retains, adds, and exposes.

A gate is a vector of sigmoid values between zero and one. The forget gate \(f_t\) controls retained cell content. The input gate \(i_t\) controls the new candidate, and the output gate \(o_t\) controls the exposed state.

Each gate combines the current input with the previous hidden state, using its own matrix and bias.

\[ \begin{aligned} i_{t}&=\sigma(W_{i}x_{t}+U_{i}h_{t-1}+b_{i}),\\ f_{t}&=\sigma(W_{f}x_{t}+U_{f}h_{t-1}+b_{f}),\\ o_{t}&=\sigma(W_{o}x_{t}+U_{o}h_{t-1}+b_{o}) \end{aligned} \tag{15.6}\]

For hidden width \(H\), the input matrices have shape \([H,d]\) and the recurrent matrices have shape \([H,H]\). Concatenating \(x_t\) with \(h_{t-1}\) and joining the matrices gives an equivalent single affine calculation. A gate preactivation of zero produces sigmoid value \(0.5\).

The candidate \(g_t\) proposes new cell content through \(\tanh\). The symbol \(\odot\) means coordinatewise multiplication. The complete state update is:

\[ \begin{aligned} g_{t}&=\tanh(W_{g}x_{t}+U_{g}h_{t-1}+b_{g}),\\ c_{t}&=f_{t}\odot c_{t-1}+i_{t}\odot g_{t},\\ h_{t}&=o_{t}\odot\tanh(c_{t}) \end{aligned} \tag{15.7}\]

The forget term retains part of \(c_{t-1}\), and the input term adds part of \(g_t\). The output gate then selects how much of \(\tanh(c_t)\) becomes visible in \(h_t\). Gates can preserve one coordinate while replacing another.

For one coordinate, take \(c_{t-1}=0.5\), \(g_t=0.4\), \(f_t=0.8\), \(i_t=0.3\), and \(o_t=0.6\). Retained content is \(0.8(0.5)=0.4\), and new content is \(0.3(0.4)=0.12\). Thus \(c_t=0.52\) and \(h_t=0.6\tanh(0.52)\approx0.286620\).

In a separate half-open-gate example, \(f_t=i_t=o_t=0.5\), \(c_{t-1}=0\), and \(g_t=0.38\). The new cell value is \(0.19\), and the exposed state is \(0.5\tanh(0.19)\approx0.093873\).

Holding the gates fixed, the direct derivative of \(c_t\) with respect to \(c_{t-1}\) is \(f_t\). Values near one can preserve this part of the gradient across steps. Other paths pass through the gates’ dependencies, so an LSTM does not eliminate every gradient problem.

A gated recurrent unit, or GRU, uses update and reset gates without a separate cell-state tensor. It offers another controlled recurrent update with less carried state than an LSTM of the same width. Both still depend on the previous step.

15.6 Layers, directions, and cost

A gated cell defines one transition. A library layer applies it across a sequence and may stack several layers or run in both directions. These choices change the returned tensors and the information available to each output.

A deep recurrent network feeds one recurrent layer’s outputs into another. A bidirectional network combines a forward pass with a reverse pass. The latter uses later input positions, so it requires the relevant complete input sequence.

The following PyTorch example supplies two sequences with five steps and three input features. It uses two bidirectional LSTM layers, each with hidden width four. The example checks dimensions rather than training a predictor.

Code example: Deep bidirectional LSTM dimensions

import torch
import torch.nn as nn

torch.manual_seed(7)
batch, steps, input_width, hidden_width = 2, 5, 3, 4
inputs = torch.randn(batch, steps, input_width)

lstm = nn.LSTM(
    input_size=input_width,
    hidden_size=hidden_width,
    num_layers=2,
    batch_first=True,
    bidirectional=True,
)
outputs, (final_hidden, final_cell) = lstm(inputs)

print(outputs.shape)       # [batch, steps, 2 * hidden_width]
print(final_hidden.shape)  # [layers * directions, batch, hidden_width]
print(final_cell.shape)
assert outputs.shape == (2, 5, 8)
assert final_hidden.shape == final_cell.shape == (4, 2, 4)

The output shape is \([2,5,8]\): each position contains four coordinates from each direction of the top layer. The final hidden and cell tensors both have shape \([4,2,4]\). Their first axis combines two layers and two directions.

To obtain both completed directional states, use the final-state tensor. The reverse half of the output at the last input position has only begun its reverse traversal. It is not the completed reverse summary of the sequence.

For padded batches, select final valid positions or use an appropriate packed-sequence procedure. Processing padding as ordinary steps can change the returned state. Bidirectional processing also requires correct lengths when identifying each sequence’s boundaries.

Bidirectionality suits a complete-input classification or tagging task. It leaks future information in causal next-token generation. An encoder may read a complete source sequence bidirectionally while a separate output generator remains causal.

Recurrence has a compact carried state, but its critical path contains \(T\) dependent updates for \(T\) positions. Training also stores intermediate values for backward computation unless recomputation or truncation changes that requirement. Increasing the state width adds matrix operations and parameters at every step.

The character-model experiment in Section 24.4 connects these output shapes to training and generation. Its prefixes and decoding comparisons test how the carried state affects later predictions.

Attention changes the connection between positions: a query can directly combine information from several permitted sources. Chapter 16 develops that calculation and its different memory costs.
