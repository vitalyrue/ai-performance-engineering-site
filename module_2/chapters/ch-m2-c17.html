17  Transformer blocks

Attention combines information from permitted positions. A deep sequence model also needs to distinguish order, preserve useful signals, and transform the features at each position. A transformer block brings those operations together while keeping a consistent representation width.

We first develop its components, then follow their tensors through a complete layer. A final variant replaces one feature transformation with several selectively activated networks.

17.1 Multiple attention heads

One attention calculation produces one set of source weights per query. Multi-head attention provides several such calculations, allowing different learned projections to combine source information in different ways.

An attention head has its own query, key, and value projections. Each head applies the score, mask, normalization, and value mixture from Chapter 16.

\[ \operatorname{head}_i=\operatorname{Attention}(XW_{Q,i},XW_{K,i},XW_{V,i}) \tag{17.1}\]

For model width \(D\) and \(H\) heads, a common configuration sets each head’s width to \(d_h=D/H\). That configuration requires \(D\) to be divisible by \(H\). Other designs can use different projection widths, but this chapter uses equal widths.

The head outputs are concatenated along their feature axis. An output projection then mixes those concatenated coordinates and returns model width \(D\).

\[ \operatorname{MHA}(X)=\operatorname{concat}(\operatorname{head}_1,\ldots,\operatorname{head}_H)W_O \tag{17.2}\]

The output projection does not introduce new token-to-token comparisons. Each head has already combined positions through its own attention weights.

Implementations often calculate all projections together in shape \([B,T,D]\). They then split the last axis into heads and move the head axis before the token axis.

\[ Q_{\mathrm{heads}}=\operatorname{reshape}(Q,B,T,H,d_h)\mathbin{.}\operatorname{permute}(0,2,1,3) \tag{17.3}\]

Here \(B\) is batch size, \(T\) is sequence length, and \(d_h\) is head width. The reshape first produces \([B,T,H,d_h]\). The permutation \((0,2,1,3)\) then produces \([B,H,T,d_h]\). Reshaping alone does not perform this axis exchange.

For \(B=2\), \(T=4\), \(D=8\), and \(H=2\), the intermediate shape is \([2,4,2,4]\) and the attention-ready shape is \([2,2,4,4]\). One head’s vectors have shape \([2,4,4]\). Two heads concatenate back to width eight.

The following index example uses unequal token and head counts so their roles remain visible. Head 0 receives coordinate pairs \((0,1)\), \((4,5)\), and \((8,9)\) from the three tokens.

Code example: Tracing coordinate values through the head split

import torch

q = torch.arange(12).reshape(1, 3, 4)
split = q.reshape(1, 3, 2, 2)
heads = split.permute(0, 2, 1, 3)
print(heads[0, 0])
assert torch.equal(heads[0, 0], torch.tensor([[0, 1], [4, 5], [8, 9]]))
restored = heads.permute(0, 2, 1, 3).reshape(1, 3, 4)
assert torch.equal(restored, q)

For different query and source lengths, the complete shapes are \(Q:[B,H,T_q,d_h]\) and \(K,V:[B,H,T_k,d_h]\). Scores have shape \([B,H,T_q,T_k]\), normalized over the final source axis. The output has shape \([B,H,T_q,d_h]\) before recombination.

Heads need not specialize into stable linguistic categories. Their value depends on training and available width. Increasing their count while fixing total width makes each head narrower. Section 24.5 compares at least two heads under controlled inputs.

17.2 Position information

Multiple heads supply different comparisons, but content vectors alone do not identify a token’s location. Without positional information or an order-dependent mask, self-attention is permutation-equivariant: reordering its input rows reorders its output rows correspondingly.

The sentences “dog bites man” and “man bites dog” illustrate why order matters. A causal mask supplies an ordering constraint through visibility. Position information can additionally represent particular locations or distances between tokens.

An absolute positional encoding assigns a vector to each position and adds it to the token representation. Those vectors may be learned or constructed from a fixed rule. A relative position bias instead changes attention scores according to the distance between query and source positions.

Attention with Linear Biases, or ALiBi, assigns each head a positive slope \(m_h\). For an allowed causal source \(j\le i\), it subtracts a distance penalty from the scaled dot product.

\[ \operatorname{score}_{i,j,h}=\frac{q_i^{T}k_j}{\sqrt{d_k}}-m_h(i-j),\quad j\le i,\quad m_h>0 \tag{17.4}\]

A head with slope \(0.1\) subtracts \(0.3\) for distance three. The bias changes the softmax weights without changing the query or key vectors. Future positions still receive the causal mask’s negative infinity.

Rotary positional embedding, or RoPE, incorporates position by rotating paired query and key coordinates. For a pair \((a,b)\) at position \(t\), a rotation frequency \(\omega\) gives \((a\cos(t\omega)-b\sin(t\omega),\ a\sin(t\omega)+b\cos(t\omega))\).

Different coordinate pairs use different frequencies. Let \(R_t\) denote one such rotation. The rotated dot product is \((R_iq)^\top(R_jk)=q^\top R_{j-i}k\), so it depends on the relative angle between positions.

For a two-coordinate example, \((1,0)\) at angle zero remains \((1,0)\). Rotating it by \(90^\circ\) gives \((0,1)\). Comparing these two rotated vectors produces dot product zero, while comparing two unrotated copies produces one.

RoPE changes the comparison vectors before their dot product. It does not append an extra value vector. The rotation preserves a vector pair’s length while changing its direction.

A positional rule that can be evaluated at larger indices does not guarantee accurate long-context predictions. Training lengths, frequencies, attention patterns, and data all affect behavior beyond the observed range. Test the required lengths rather than inferring capability from the encoding alone.

17.3 Residuals and normalization

After attention combines positions, its output must enter the next transformation. Repeatedly replacing every representation can make a deep stack difficult to optimize. A residual connection adds a transformation to its input, allowing the layer to learn an adjustment.

For \(y=x+F(x)\), the derivative is \(I+J_F\), where \(J_F\) is the Jacobian of the transformation. The direct path contributes the identity term. It provides another gradient route, although cancellation or growth can still occur.

Both sides of the addition must have compatible dimensions. Transformer sublayers normally return the full model width \(D\) before adding to the incoming representation, called the residual stream. If one coordinate is 2 and its computed adjustment is \(0.3\), the result is \(2.3\).

Layer normalization, or LayerNorm, normalizes the features of each token independently. For one \(D\)-coordinate vector, it computes the feature mean \(\mu\) and population variance \(\sigma^2\).

\[ \operatorname{LN}(x)=\frac{\gamma(x-\mu)}{\sqrt{\sigma^{2}+\varepsilon}}+\beta \tag{17.5}\]

The learned vectors \(\gamma\) and \(\beta\) scale and shift the normalized coordinates. The positive constant \(\varepsilon\) keeps the denominator defined when variance is small. No statistics are combined across examples or token positions.

For \(x=(2,4)\), the mean is 3 and the variance is 1. Ignoring a small \(\varepsilon\) and using unit scale with zero shift gives approximately \((-1,1)\). The separate vector \((1,3)\) has mean 2 and also produces approximately \((-1,1)\) under those settings.

Root mean square normalization, or RMSNorm, divides by the root mean square of the features without subtracting their mean.

\[ \operatorname{RMSNorm}(x)=\frac{\gamma x}{\sqrt{\operatorname{mean}_{j}(x_j^{2})+\varepsilon}} \tag{17.6}\]

For \(x=(3,4)\), the mean square is \(12.5\) and its square root is approximately \(3.535534\). With unit scale and negligible \(\varepsilon\), the result is approximately \((0.848528,1.131371)\). Unlike LayerNorm, this operation does not center the vector.

Both methods preserve the token and batch axes. RMSNorm avoids computing and subtracting the mean, although its practical performance depends on the implementation and hardware.

The axes matter when comparing this operation with batch normalization, or BatchNorm. For an array of examples shaped \([N,C]\), BatchNorm computes a mean and variance for each of the \(C\) channels across the \(N\) examples. With rows \((2,4)\) and \((1,3)\), its channel means are \((1.5,3.5)\). LayerNorm instead uses each row’s own features, giving the row means 3 and 2 calculated above. Changing the other examples in a batch can therefore change a training-time BatchNorm result.

By default, PyTorch’s BatchNorm1d tracks running statistics during training and uses them during evaluation. Setting track_running_stats=False uses current batch statistics in both modes. For input shaped \([N,C,L]\), it combines the example and length axes when calculating each channel’s statistics. The PyTorch 2.11 BatchNorm1d contract specifies these choices. The transformer block here uses LayerNorm over each token’s feature width, so it needs no batch-statistics estimate for evaluation.

A pre-norm block normalizes the input before applying the sublayer and adding its result to the original input.

\[ x_{l+1}=x_l+F(\operatorname{LN}(x_l)) \tag{17.7}\]

A post-norm block applies normalization after the residual addition.

\[ x_{l+1}=\operatorname{LN}(x_l+F(x_l)) \tag{17.8}\]

In the pre-norm form, the residual stream bypasses that normalization. In the post-norm form, the whole residual sum passes through it. If a post-norm residual sum is \((1,3)\), its centered values are \((-1,1)\) before scale and shift.

Replacing LayerNorm with RMSNorm gives a different pre-norm variant. These layouts affect gradient paths and training behavior. A direct residual path helps optimization, but does not guarantee stable training at arbitrary depth.

17.4 Feed-forward layers

Attention changes a token by combining information from other positions. The feed-forward network, or FFN, then transforms that token’s coordinates using the same network at every position. This operation introduces no new cross-position reads.

For one token represented as a column vector, a basic FFN is the MLP from Chapter 12:

\[ \operatorname{FFN}(x)=W_2\phi(W_1x+b_1)+b_2 \tag{17.9}\]

The first matrix expands the width, \(\phi\) supplies a nonlinear activation, and the second matrix returns to width \(D\). One common intermediate width is \(4D\).

\[ W_1\in\mathbb{R}^{4D\times D},\quad W_2\in\mathbb{R}^{D\times4D} \tag{17.10}\]

For \(D=768\), the intermediate width is 3,072. Across a batch, an input \([B,T,D]\) becomes \([B,T,4D]\) and returns to \([B,T,D]\). These two matrices contain about \(8D^2\) weights before biases, explaining why the FFN can account for substantial parameters and arithmetic.

The scalar case \(x=1\), \(W_1=2\), \(b_1=0.5\), identity activation, \(W_2=3\), and \(b_2=1\) gives output \(3(2+0.5)+1=8.5\). Identity activation isolates the affine arithmetic here. A useful nonlinear FFN applies an activation between its projections.

The Gaussian error linear unit, or GELU, multiplies a value by the standard normal cumulative probability at that value.

\[ \operatorname{GELU}(x)=x\Phi(x) \tag{17.11}\]

Here \(\Phi(x)\) is the probability that a standard normal variable is at most \(x\). Thus \(\operatorname{GELU}(0)=0\) and \(\operatorname{GELU}(1)\approx0.841345\). Negative inputs are smoothly suppressed rather than abruptly set to zero as in ReLU.

A gated linear unit, or GLU, multiplies one projected branch by a gate derived from another. The SiLU activation, also called Swish for this form, is \(\operatorname{SiLU}(b)=b\sigma(b)\). SwiGLU uses that activation in its gating branch.

\[ \operatorname{SwiGLU}(x)=W_c\!\left[(W_a x)\odot\operatorname{SiLU}(W_bx)\right],\quad\operatorname{SiLU}(u)=u\sigma(u) \tag{17.12}\]

Here \(W_a,W_b\) have shape \([H_f,D]\), and \(W_c\) has shape \([D,H_f]\). The two expanded branches multiply coordinatewise before the output projection. Biases are omitted to keep this operation visible.

For scalar branches \(a=2\) and \(b=0\), SwiGLU’s intermediate value is \(a\operatorname{SiLU}(b)=2(0)(0.5)=0\). A sigmoid-only GLU would instead give \(a\sigma(b)=1\). The factor \(b\) is necessary to distinguish the two activations.

For \(a=2\) and \(b=1\), the SwiGLU intermediate is \(2\sigma(1)\approx1.462117\). These gates act on features within one token. They serve a different role from attention weights over source positions.

17.5 Assembling the block

The components now have compatible interfaces. A transformer block alternates attention across positions with an FFN at each position, adding a residual around each sublayer. Repeating the block creates network depth.

Using pre-LayerNorm, the two updates are:

\[ \begin{aligned}X_1&=X+\operatorname{Attention}(\operatorname{LN}(X)),\\X_2&=X_1+\operatorname{FFN}(\operatorname{LN}(X_1))\end{aligned} \tag{17.13}\]

Here Attention includes the multiple-head calculation and its output projection. Both \(X_1\) and \(X_2\) retain shape \([B,T,D]\). Positional information must be supplied by the selected encoding or attention rule.

Take \(B=1\), \(T=2\), \(D=4\), and \(H=2\). Combined projections have shape \([1,2,4]\). Reshaping to \([1,2,2,2]\) first means [batch, token, head, feature]. Permuting to [batch, head, token, feature] leaves the numerical shape unchanged but changes which values each attention calculation reads.

The combined head output has shape \([1,2,2,2]\), with one \([1,2,2]\) result per head. Recombining heads restores $[1,2,4]`. An FFN can expand it to \([1,2,16]\) before returning to \([1,2,4]\) for the residual addition.

The following PyTorch layer uses LayerNorm and GELU. It receives prepared vectors of shape \([2,4,8]\), applies two attention heads, and returns the same outer shape. The supplied causal mask blocks future keys.

Code example: One pre-normalized transformer layer

import torch
import torch.nn as nn

class TransformerLayer(nn.Module):
    def __init__(self, width=8, heads=2, hidden=16):
        super().__init__()
        self.norm1 = nn.LayerNorm(width)
        self.attention = nn.MultiheadAttention(width, heads, batch_first=True)
        self.norm2 = nn.LayerNorm(width)
        self.ffn = nn.Sequential(
            nn.Linear(width, hidden),
            nn.GELU(),
            nn.Linear(hidden, width),
        )

    def forward(self, x, attention_mask=None):
        normalized = self.norm1(x)
        mixed, weights = self.attention(
            normalized,
            normalized,
            normalized,
            attn_mask=attention_mask,
            average_attn_weights=False,
        )
        x = x + mixed
        x = x + self.ffn(self.norm2(x))
        return x, weights

torch.manual_seed(7)
x = torch.randn(2, 4, 8)
blocked = torch.ones(4, 4, dtype=torch.bool).triu(1)
layer = TransformerLayer().eval()
output, weights = layer(x, attention_mask=blocked)
print(x.shape, output.shape, weights.shape)
print(weights.mean(dim=1).shape)
assert output.shape == (2, 4, 8)
assert weights.shape == (2, 2, 4, 4)
assert torch.count_nonzero(weights.triu(1)) == 0
changed = x.clone()
changed[:, -1] += 10 * torch.arange(8)
changed_output, _ = layer(changed, attention_mask=blocked)
assert torch.allclose(output[:, :-1], changed_output[:, :-1], atol=1e-6)

The returned per-head attention weights have shape \([2,2,4,4]\). Averaging their head axis gives \([2,4,4]\), which is also the library’s default return format when head averaging is enabled. Inspecting separate heads therefore requires an explicit setting.

For this MultiheadAttention API, a two-dimensional attention mask has shape \([T_q,T_k]\). A three-dimensional per-example, per-head mask has shape \([B H,T_q,T_k]\). A Boolean True entry blocks a source here, unlike the allowed-position Boolean mask used by the helper in Section 16.3.

Padding can be supplied separately with key_padding_mask shaped $[B,T_k]`. All-masked rows still require a defined policy. Match the specific API’s mask contract rather than assuming every attention interface uses the same Boolean convention.

The compact example uses no dropout. When included in training, dropout can act on attention weights or sublayer outputs, following Section 11.5. Evaluation disables it. Disabling gradient recording is a separate choice.

After the final block, a language-model output head projects each token representation to vocabulary logits.

\[ \operatorname{logits}=x_{\mathrm{final}}W_{\mathrm{vocab}}^{T} \tag{17.14}\]

Here \(x_{\text{final}}\) has shape \([B,T,D]\), and \(W_{\text{vocab}}\) has shape \([|V|,D]\). The result has shape \([B,T,|V|]\). A model may tie these weights to its input embedding table, with the gradient consequences described in Section 13.2.

The block defines the transformation. Chapter 18 will choose its permitted inputs and training targets. Before that comparison, one useful variant changes which FFN parameters execute for each token.

17.6 Mixture of experts

A dense FFN activates the same matrices for every token. A mixture-of-experts, or MoE, layer contains several alternative FFNs and selects only a subset for each input. Each alternative is an expert, and the selection module is a router.

For token vector \(x\in\mathbb R^D\) and \(E\) experts, a router matrix with shape \([E,D]\) produces \(E\) scores. Softmax converts them to probabilities \(g\). The set \(\mathcal T_k(g)\) contains the indices of the largest \(k\) probabilities.

\[ g=\operatorname{softmax}(W_{\mathrm{gate}}x),\quad y=\sum_{e\in\mathcal{T}_{k}(g)}g_{e}^{(k)}f_{e}(x) \tag{17.15}\]

Each selected expert \(f_e\) returns a \(D\)-coordinate vector. In this formulation, the selected weights are renormalized: \(g_e^{(k)}=g_e/\sum_{j\in\mathcal T_k(g)}g_j\). Their weighted outputs can therefore be added back to the residual stream.

For router scores \((\log 7,\log 3,0)\), softmax gives \((7/11,3/11,1/11)\). Selecting the largest two entries and renormalizing gives \((0.7,0.3)\). If their scalar outputs are 2 and 5, the mixture is \(0.7(2)+0.3(5)=2.9\).

Across \(B\) sequences of \(T\) tokens, router scores have shape \([B,T,E]\). The selected expert outputs retain width \(D\), and the final mixture has shape \([B,T,D]\).

Sparse activation means only some expert parameters execute for a token. It can increase total parameter capacity without activating every expert each time. Router computation, dispatch, and communication still add cost, and all expert weights need storage somewhere.

Load balancing encourages a useful distribution of tokens across experts. If most tokens select one expert, it becomes a bottleneck while others receive little training. Capacity limits may also require a policy for overflow tokens.

One training approach perturbs router scores with Gaussian noise before selecting the largest entries. This changes which experts receive examples during exploration. An auxiliary loss can also penalize uneven total gate weight across a batch. The sparsely gated MoE paper develops noisy gating and balancing objectives.

For positive expert importance values \(I_e\), the coefficient of variation is their standard deviation divided by their mean. Importance totals \((9,1)\) have mean five and population standard deviation four, so their squared coefficient is \(0.64\). Totals \((5,5)\) give zero. Adding a scaled penalty encourages balanced importance during training. It does not guarantee balanced traffic in each inference batch, and equal gate weight need not mean equal execution time.

An expert capacity limits how many assigned tokens it can process in a dispatch. If capacity is two and three tokens select it, the implementation needs an overflow rule, such as rerouting or skipping that expert branch. State the actual rule because it changes the computation. Increasing capacity reduces overflow risk while increasing memory requirements.

Top-\(k\) selection is discrete. Gradients pass through selected expert computations and their weights, while the selection boundary itself is not a smooth operation. Balancing objectives and routing rules affect both training and runtime behavior.

MoE is a choice for conditional computation within a model. It does not require multiple input modalities. The following chapter compares architecture and objective choices independently of this FFN variant.

Chapter checkpoint

A head split has the expected shape but produces different attention weights after a refactor. What evidence would distinguish a shape check from an axis check?

Feedback: Trace identifiable coordinate values through reshape and permutation, then reconstruct the original tensor. Equal dimension sizes can hide an incorrect axis exchange.

A claimed SwiGLU implementation returns 1 when its branches are \(a=2\) and \(b=0\). Which operation is missing?

Feedback: SiLU multiplies the sigmoid by its own input. The SwiGLU intermediate should be \(a b\sigma(b)=0\). Returning 1 indicates a sigmoid-only gate in this example.

An MoE model has more parameters but no latency improvement. Which costs would you measure?

Feedback: Measure active expert computation, routing and dispatch, communication, and the distribution of tokens across experts. Total parameter count alone does not determine per-token latency.
