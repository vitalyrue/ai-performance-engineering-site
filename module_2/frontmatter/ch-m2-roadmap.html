Roadmap

A useful model must produce the right kind of output, learn from appropriate data, and behave reliably on new examples. This book develops the calculations behind those requirements. It connects text representations and prediction errors to model training, generated answers, and resource costs.

Artificial intelligence, or AI, is the broad field of systems that perform tasks associated with perception, reasoning, prediction, or generation. Machine learning, or ML, develops their behavior from data. Deep learning uses multilayer neural networks to learn intermediate representations.

A language model assigns probabilities to token sequences or missing tokens in context. A large language model, or LLM, uses a large neural network for this purpose. Generative AI produces content such as text, images, or audio. Language generation is one application within that broader group.

The book separates four decisions: what the task requires, how the model combines information, what training measures, and how an output is selected. A model family does not uniquely determine its task. The same transformer architecture can support different outputs when its inputs, objective, and prediction interface change.

Starting knowledge

The guide assumes elementary algebra, functions, sums, and basic probability. Python examples use lists, indexing, functions, and imports. Derivatives and PyTorch’s automatic differentiation are taught within the book.

A tensor is an array with explicit axes and a numerical type. Shape \([B,T,D]\) describes \(B\) examples, \(T\) positions per example, and \(D\) coordinates per position. Thus shape \([2,3,4]\) contains 24 logical values. Its device identifies where the values reside, such as CPU memory or a GPU.

Integer token IDs select vocabulary entries. Floating-point arrays hold numerical features, and Boolean arrays can indicate valid positions. 2  Token IDs and batches introduces these objects in batches. 23  Tensor storage and execution later explains their storage and execution costs.

Matrix multiplication combines values along a shared axis. If \(X\) has shape \([B,D_{in}]\) and \(W\) has shape \([D_{in},D_{out}]\), then \(XW\) has shape \([B,D_{out}]\). Scoring a batch develops the calculation and PyTorch’s stored weight orientation. ?sec-ch-m2-notation provides a reference while reading.

Two representation routes share the initial task definition. Count-based document features can feed a classifier, while token IDs select learned vectors for a sequence model. Neither route requires passing through the other.

Similarly, probabilities support two branches. 7  Decoding strategies follows output selection with fixed parameters. 8  Cross-entropy and perplexity compares outputs with targets, and 9  Validation and testing evaluates new examples. The gradient chapter, 10  Backpropagation, precedes the optimizer comparison in 11  Momentum and AdamW.

For text classification, continue through nonlinear models, embedding lookup, and Word2Vec in Chapters 12–14, then use Text classification with learned embeddings. For sequence modeling, compare the count baseline in Fixed histories with recurrence before attention and transformers. The corresponding experiments follow the same order in 24  Experiments and system integration.

For adaptation and serving, complete Chapters 17–21 before the two-model experiment in Adapting answers to the reader. The multimodal experiment in Multimodal components and combined answers combines reference retrieval with a separate answer component. Its error records connect the final system back to the original task definition.

This is a mathematics companion to the performance engineering course. It explains the objects and calculations needed to inspect model quality, training, and inference. Kernel programming, Tensor Core scheduling, memory coalescing, and complete distributed deployment configurations belong to the performance guide.

Mixed precision, serving engines, and timing appear here where they affect a numerical assumption, memory estimate, or experimental choice. The book does not provide a full production deployment recipe for each library it mentions.

Model objects and families

Following an example through a model is easier when its data objects remain distinct. The table below is an orientation reference. Each linked chapter develops the calculation rather than assuming the summary is sufficient preparation.

Object or decision | Meaning | Full explanation | |—|—|—| | Examples and targets | Observed inputs and the outputs the task requires | 1  Prediction targets | | Task | Numeric prediction, class selection, sequence prediction, or a useful learned representation | 1  Prediction targets and 18  Transformer architectures | | Representation | Token IDs, masks, feature vectors, and batches supplied to a model | Chapters 2–4 and 13  Embedding tables | | Parameters | Weights, biases, embedding tables, and projections changed by training | 5  Linear scores and 10  Backpropagation | | Activations and logits | Intermediate values and unnormalized output scores | 12  Activation functions and 6  Sigmoid and softmax | | Loss and gradient | An objective value and its sensitivity to parameter changes | 8  Cross-entropy and perplexity and 10  Backpropagation | | Optimizer state | Persistent information used by an update rule, such as momentum | 11  Momentum and AdamW | | Inference state | Request-specific values, including selected tokens and cached attention keys and values | 7  Decoding strategies and 21  KV cache and serving |

Regression returns a numerical estimate. Classification selects labels, including multiple independent labels when the task requires them. Sequence objectives can predict the next token, reconstruct hidden positions, or generate a target sequence from an input. Representation learning instead develops vectors for downstream use. These objectives are distinguished in 1  Prediction targets, 14  Word2Vec, and 18  Transformer architectures.

A model family controls how available input information can influence a prediction. Recurrent neural networks, or RNNs, carry state through positions. Long short-term memory networks, or LSTMs, add gates to that state. Transformers use attention over permitted positions. The following comparison identifies their teaching locations.

Training and inference also have different purposes. Training changes parameters using a loss and an update rule. Inference applies the current parameters to an input. Evaluation uses held-out examples to assess the result without treating their target labels as another training batch.

References and execution guidance

?sec-ch-m2-notation collects symbols, dimensions, and mask conventions. ?sec-ch-m2-library-map connects library operations to their explanations and exercises. The appendix, Appendix A — Dictionary, expands abbreviations and links back to their definitions.

A complete code example checks its stated inputs and outputs. A fragment requires the surrounding objects identified in its introduction. A full experiment additionally requires the dataset split, model revision, training or inference configuration, and observed results.

24  Experiments and system integration states those experiment requirements and separates source assignments from book extensions. Passing a shape assertion establishes neither model quality nor a speed improvement. Keep numerical checks, task evaluation, and resource measurements distinct when drawing a conclusion.
