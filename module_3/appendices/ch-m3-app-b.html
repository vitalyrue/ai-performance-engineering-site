Appendix B — MLOps glossary

MLOps combines vocabulary from infrastructure, distributed systems, model evaluation, storage, retrieval, and orchestration. The same term can connect several components, so each definition names the object, behavior, or measurement involved. The entries use consistent meanings across training, serving, evaluation, storage, and pipelines.

Access pattern. The measurable read/write, size, concurrency, sharing, durability, latency, and lifecycle behavior of data.

Agent trajectory. The ordered model, reasoning-state, tool-call, observation, and state-transition path taken by an agent.

All-reduce. A collective that combines values from all ranks and returns the result to every rank.

ANN. Approximate nearest-neighbor retrieval that prunes the search space instead of comparing every vector.

Artifact. A versionable product of a run, such as a checkpoint, dataset manifest, image, metric report, or index.

Backfill. Execution of a pipeline for historical logical intervals or previously unprocessed partitions.

Batching. Combining multiple items or requests so one compute operation uses hardware more efficiently.

Blue/green deployment. A release pattern that keeps stable and candidate environments available for a controlled traffic switch.

Canary. A candidate release exposed to a small controlled share of live traffic before wider promotion.

Checkpoint. A saved state sufficient to resume a computation under stated compatibility conditions.

Chunk. A bounded source segment used as one embedding and retrieval unit, with links back to its source.

Cold start. Latency and failure risk incurred when a service creates capacity and loads runtime/model state before serving.

Collective. A coordinated communication operation involving a defined group of distributed ranks.

Consistency (evaluator). The fraction of repeated judgments that agree with the modal label for one unchanged case.

Context parallelism. Distribution of long sequence context across devices to reduce per-device memory or computation.

Control plane. The component that stores desired state and reconciles deployments, capacity, configuration, and rollout actions.

Critical path. The longest dependency path whose summed duration lower-bounds a DAG’s completion time.

Data drift. A change in the production input distribution relative to a reference distribution.

Data parallelism. Replicated computation over distinct input shards with synchronized model updates.

DAG. A directed acyclic graph representing tasks and prerequisite relationships.

DDP. PyTorch’s replicated-model distributed data-parallel implementation with gradient synchronization.

Decode. Autoregressive generation after prefill, usually one next-token step per active sequence.

Disaggregated serving. Separation of serving stages such as prefill and decode into independently scheduled capacity.

Distributed sampler. A deterministic policy that partitions dataset examples among data-parallel ranks.

Embedding. A model-produced fixed-length numeric representation used to compare items in a vector space.

Evaluator. A deterministic rule, model, or human protocol that maps system evidence to a quality judgment.

Experiment run. One traceable execution with recorded parameters, code, inputs, outputs, metrics, and environment.

Expert parallelism. Distribution of mixture-of-experts components and token routing across devices.

F1 score. The harmonic mean of precision and recall.

FSDP. Fully Sharded Data Parallel, which shards selected model, gradient, and optimizer state across ranks.

Gang scheduling. Admission of all resources required by a coordinated distributed job as one placement decision.

Groundedness. The extent to which an answer’s material claims are supported by the supplied evidence.

HNSW. A layered proximity-graph ANN index with tunable construction and search effort.

Hybrid retrieval. Combination of dense, sparse, metadata, and optional reranking stages.

Idempotency. The property that safe repeated execution has the same externally visible result as one execution.

Inference engine. The runtime that schedules model forward passes, manages memory/KV state, and emits generated tokens.

Inter-token latency. Elapsed time between successive generated tokens during decode.

IOPS. Completed storage input/output operations per second for a stated operation shape.

IVF. An inverted-file ANN method that searches selected coarse vector partitions.

KV cache. Stored attention keys and values reused across autoregressive decode steps.

Lineage. The recorded graph connecting outputs to exact inputs, code, configuration, environment, and producer run.

Log. A discrete timestamped event record with structured diagnostic context.

Metric. A numeric time series aggregated over events or measurements.

MFU. Model FLOPs Utilization: observed model arithmetic rate divided by relevant hardware peak.

Model registry. A governed store of immutable model versions, lineage, metadata, and promotion state.

NCCL. NVIDIA’s communication library implementing GPU-oriented collective operations.

Object storage. API-addressed storage for named objects with semantics distinct from a POSIX file system.

OpenTelemetry. An open standard and SDK/protocol family for traces, metrics, and logs.

Pipeline parallelism. Distribution of consecutive model layers across stages that exchange activations and gradients.

Prediction drift. A change in the distribution of model outputs relative to a reference.

Prefill. Parallel processing of input prompt tokens to create the initial KV state.

Prompt decision tree. An explicit ordered representation of evaluator decisions, overrides, and terminal verdicts.

Quantization. Representation of weights, activations, or cache values with reduced numerical precision.

Rank. One process identity in a distributed process group; global and local ranks serve different scopes.

Recall@k. The fraction of relevant reference items found among the top-k retrieved results.

Recovery Point Objective. The maximum acceptable amount of work or data lost after failure.

Recovery Time Objective. The target time to restore an acceptable level of service or computation.

Rendezvous. The discovery and coordination mechanism through which distributed ranks form a process group.

Reranker. A more expensive scorer applied to a reduced candidate set to improve final ordering.

Serving bundle. The immutable weights, tokenizer, engine image, configuration, compatibility, and release metadata deployed together.

Service Level Objective. A measurable target for service behavior over a defined population and time window.

Speculative decoding. Generation that proposes tokens with a draft model and verifies them with the target model.

Tensor parallelism. Distribution of tensor operations within a model layer across devices.

Time to First Token. Elapsed time from request admission to the first generated token.

Trace. A causally ordered set of spans describing one operation across components.

Vector database. A stateful service that stores vector records and metadata and supports similarity-oriented retrieval.

World size. The number of processes participating in a distributed process group.
