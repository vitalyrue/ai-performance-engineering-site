Part VI: Assessing AI in cyber work

The same methods that help a defender analyze information can help an attacker. This part separates capability claims, observed misuse, and measured defensive value. It also treats a security assistant as an AI system requiring the controls already taught.

Connection through the book. Change AI’s role while retaining the earlier method. First assess claims that an attacker used AI, then build a defensive analyst assistant using the retrieval and action controls already taught. Compare model and hosting choices only after the task and useful outcome are defined.

Part outcome. A measured decision about where AI helps a security task and what oversight and operating cost it requires.

Chapters in this part

  • Assessing AI-assisted harm: This chapter assesses claims about AI-assisted harm by separating demonstrated capability, observed use, prevalence, and the defensive controls justified by the evidence.
  • Using AI safely in defense: This chapter applies the book’s safeguards to a security team’s own AI assistant, keeping human judgment and action authority visible while measuring useful work.
  • Choosing a viable deployment: This chapter compares external, managed, and internal model choices only after the organization has fixed the task, data access, quality target, action limits, and full operating cost.
